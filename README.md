# SmartTag VAK — автоматическая классификация научных статей по специальностям ВАК

## О проекте

SmartTag VAK — это система обработки и классификации научных статей по пяти специальностям Высшей аттестационной комиссии (ВАК):

- `1.2.2` Математическое моделирование, численные методы и комплексы программ
- `2.3.1` Системный анализ, управление и обработка информации
- `2.3.3` Автоматизация и управление технологическими процессами и производствами
- `2.3.5` Математическое и программное обеспечение вычислительных систем, комплексов и компьютерных сетей
- `2.4.5` Энергетические системы и комплексы

**Основные возможности:**

- полный пайплайн: скачивание PDF → парсинг → LDA → кластеризация → классификация ВАК
- локальное GUI‑приложение (Tkinter) для ручного ввода данных статьи
- пакетная классификация через `pandas.DataFrame`
- **гибридная классификация ВАК**:
  - TF‑IDF (полные описания специальностей) → основной рейтинг `match_score` (min‑max нормализация, 0–100%)
  - эмбеддинги (sentence‑transformers) → `semantic_similarity` и флаги расхождения (`discrepancy`) между двумя методами
- флаги неоднозначности (`ambiguous`) и расхождения (`discrepancy`) для информирования пользователя
- возможность просмотреть все пять специальностей с рангами TF‑IDF и эмбеддингов (режим «Подробнее» в GUI)

Код написан на Python, данные хранятся в CSV (папка `project_data/`)

## Структура репозитория

```
SmartTag-VAK/
├── backend/ # Основная логика
│ ├── config.py # Пути к данным (PROJECT_ROOT, DEFAULT_DATASET_CSV и др.)
│ ├── main.py # Точка входа для полного пайплайна
│ ├── pipeline/ # Интерактивный пайплайн (runner.py)
│ ├── stages/ # Самодостаточные этапы:
│ │ ├── setup/ # Инициализация проекта, NLTK stopwords
│ │ ├── scraper/ # Скачивание PDF с сайта IMT Journal
│ │ ├── parser/ # Парсинг PDF → структурированный CSV
│ │ ├── lda/ # Тематическое моделирование LDA
│ │ └── clustering/ # Кластеризация статей на эмбеддингах
│ ├── vak_classifiers/ # Классификатор ВАК
│ └── vak_data/ # Данные ВАК, загрузка CSV, сборка текста
├── frontend/ # GUI на Tkinter
│ └── tkinter_app.py # Окно для ввода и отображения результатов
├── project_data/ # Создаётся автоматически, содержит:
│ ├── pdfs/imt/ # Скачанные PDF
│ ├── dataset_IMT.csv # Результат парсинга
│ ├── lda_results/ # LDA-модели и графики
│ ├── clustering_results/ # CSV с кластерами, t‑SNE, силуэты
│ └── vak_results/ # Результаты классификации ВАК
├── requirements.txt # Зависимости проекта
└── README.md # Этот файл
```
