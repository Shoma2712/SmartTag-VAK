# SmartTag VAK

**Система автоматического анализа научных статей и их классификации по специальностям ВАК**

Проект для выявления оптимального количества рубрик для корпуса статей журнала "Информационные и математические технологии в науке и управлении" и их автоматической классификации по пяти специальностям Высшей аттестационной комиссии (ВАК) Российской Федерации.

---

## Возможности

- **Двухметодная классификация:** TF-IDF (статистический анализ) + Sentence Embeddings (семантический анализ)
- **Тематическое моделирование:** автоматическое выявление скрытых тем с помощью LDA
- **Кластеризация:** группировка статей по семантической близости с использованием K-means
- **Интеллектуальные подсказки:** выявление неоднозначных случаев и расхождений между методами
- **База данных SQLite:** централизованное хранение всех результатов
- **Графический интерфейс:** удобный UI для классификации новых статей
- **Сохранение результатов:** возможность сохранения классификаций в БД с заметками

---

## Специальности ВАК

Система классифицирует статьи по пяти специальностям:

1. **1.2.2** — Математическое моделирование, численные методы и комплексы программ
2. **2.3.1** — Системный анализ, управление и обработка информации
3. **2.3.3** — Автоматизация и управление технологическими процессами и производствами
4. **2.3.5** — Математическое и программное обеспечение вычислительных систем, комплексов и компьютерных сетей
5. **2.4.5** — Энергетические системы и комплексы

## База данных

Система использует SQLite для централизованного хранения:

| Таблица | Назначение |
|---------|------------|
| `articles` | Статьи с метаданными и текстами |
| `lda_results` | Результаты тематического моделирования |
| `clustering_results` | Принадлежность статей к кластерам |
| `vak_results` | Результаты классификации по ВАК (оба метода) |
| `saved_classifications` | Сохранённые результаты из UI с заметками |
| `cluster_vak_tfidf_distribution` | Аналитика распределения специальностей (TF-IDF) |
| `cluster_vak_embed_distribution` | Аналитика распределения специальностей (Embeddings) |

**Схема:** См. `backend/database.py`

**Просмотр:** Используйте DB Browser for SQLite или любой SQLite клиент

## Методы классификации

### TF-IDF (основной метод)

- Статистический анализ частоты терминов
- Сравнение с полными описаниями специальностей ВАК
- Используется для выявления расхождений и альтернативных рекомендаций

### Sentence Embeddings (валидация)

- Семантический анализ через нейросетевые модели
- Сравнение с короткими описаниями специальностей ВАК


## Использование

### Графический интерфейс

1. Запустите: `python -m frontend.tkinter_app`
2. Введите данные статьи (название, аннотация, ключевые слова)
3. Нажмите «Подобрать специальность ВАК»
4. Просмотрите результаты:
   - Топ-3 специальности с нормализованными оценками
   - Флаги неоднозначности и расхождения
   - Детальный просмотр всех 5 специальностей (опционально)
5. Сохраните результаты в БД с заметками (кнопка «Сохранить в БД»)

### Пайплайн обработки

```bash
python main.py
```

Интерактивный режим с выбором этапов:
1. Инициализация проекта
2. Сбор PDF (опционально)
3. Парсинг PDF → таблица `articles`
4. LDA → таблица `lda_results`
5. Кластеризация → таблица `clustering_results`
6. Классификация ВАК → таблица `vak_classifications`
7. Аналитика → таблицы `cluster_vak_distribution_*`

---

### Флаги

- **Неоднозначность** — малый разрыв между топ-1 и топ-2
- **Расхождение** — методы TF-IDF и embeddings выбрали разные специальности
- **Альтернативная рекомендация** — статистический метод предлагает рассмотреть другую специальность
