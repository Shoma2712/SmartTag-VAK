# Полный Пайплайн (`backend.pipeline`)

## Описание

Модуль запускает **весь цикл обработки** в консоли с интерактивными вопросами на каждом этапе. Все результаты сохраняются в **базу данных SQLite** (`project_data/smarttag_vak.db`):

1. **Инициализация проекта** — создание структуры папок и базы данных
2. **Сбор PDF** — опциональная загрузка статей с сайта журнала
3. **Парсинг PDF** — извлечение текста и метаданных, сохранение в таблицу `articles`
4. **LDA** — тематическое моделирование, сохранение в таблицу `lda_results`
5. **Кластеризация** — группировка статей, сохранение в таблицу `clustering_results`
6. **Классификация ВАК** — двухметодная классификация, сохранение в таблицу `vak_classifications`
7. **Аналитика** — распределение специальностей по кластерам, сохранение в таблицы `cluster_vak_distribution_*`

На каждом этапе пользователь выбирает `y/n` — выполнить блок или пропустить.

## Запуск

```bash
python -m backend.main pipeline
```

или

```bash
python main.py
```

## Файл `runner.py`

### `run_full_pipeline() -> None`

**Вход:** интерактивные ответы пользователя в консоли.

**Выход:** печать статусов в stdout и сохранение всех результатов в базу данных SQLite.

**Что делает:** 
1. Проверяет наличие базы данных, создаёт при необходимости
2. По очереди вызывает блоки setup/scraper/parser/LDA/clustering/VAK/analytics
3. Проверяет наличие уже готовых данных в БД
4. Запрашивает подтверждение на перезапуск каждого этапа
5. Сохраняет результаты в соответствующие таблицы БД

**Новое:** Все данные хранятся в БД, CSV файлы больше не используются как основное хранилище.

---

### `_ask_yes_no(prompt: str, default: bool = False) -> bool`

**Вход:** текст вопроса и значение по умолчанию.

**Выход:** `True`/`False`.

**Что делает:** единый безопасный ввод `y/n` (поддерживает `да/нет`).

---

### `_load_or_parse_dataset(paths, pdf_count) -> pd.DataFrame`

**Вход:** пути из setup-блока и число PDF.

**Выход:** DataFrame статей из базы данных.

**Что делает:** 
- Проверяет наличие статей в таблице `articles`
- Если статей нет или пользователь хочет перепарсить — запускает парсер
- Сохраняет результаты парсинга в таблицу `articles`
- Возвращает DataFrame для дальнейшей обработки

---

### `_run_lda_if_requested(df, base_dir) -> Optional[pd.DataFrame]`

**Вход:** DataFrame статей, базовая папка `project_data`.

**Выход:** DataFrame с добавленными LDA-темами или `None`.

**Что делает:** 
- По запросу запускает `prepare_dataset_for_analysis` + `train_lda_model`
- Сохраняет результаты в таблицу `lda_results` (токены, ключевые слова тем)
- Сохраняет визуализации в `project_data/lda_results/`
- Возвращает DataFrame с темами для следующих этапов

---

### `_run_clustering_if_requested(df, base_dir) -> Optional[pd.DataFrame]`

**Вход:** DataFrame статей с LDA-темами.

**Выход:** DataFrame с добавленными кластерами или `None`.

**Что делает:** 
- По запросу запускает `cluster_articles` с автоподбором оптимального `k`
- Присваивает кластерам названия на основе доминантных тем LDA
- Сохраняет результаты в таблицу `clustering_results`
- Сохраняет визуализации (silhouette, t-SNE) в `project_data/clustering_results/`
- Возвращает DataFrame с кластерами

---

### `_run_vak_if_requested(df, base_dir) -> Optional[pd.DataFrame]`

**Вход:** DataFrame статей (с кластерами или без).

**Выход:** DataFrame с добавленными результатами классификации ВАК или `None`.

**Что делает:** 
- Запускает `VakUiClassifier.classify_dataframe` с режимом `score_mode='minmax'`
- Извлекает топ-1 специальности для обоих методов (TF-IDF и embeddings) из JSON
- Сохраняет результаты в таблицу `vak_results`:
  - `article_id` — связь со статьёй
  - `vak_tfidf_code` — код топ-1 специальности по TF-IDF
  - `vak_embed_code` — код топ-1 специальности по embeddings
- Возвращает DataFrame с результатами классификации

**Важно:** Используется нормализованный режим отображения (minmax), типичные значения сырого TF-IDF косинуса: 0.03-0.15.

---

### `_run_analytics_if_requested(df, base_dir) -> None`

**Новая функция:** Вычисляет распределение специальностей ВАК по кластерам.

**Вход:** DataFrame с результатами кластеризации и классификации ВАК.

**Выход:** сохранение статистики в таблицы `cluster_vak_distribution_tfidf` и `cluster_vak_distribution_embeddings`.

**Что делает:**
- Группирует статьи по кластерам
- Подсчитывает количество статей каждой специальности в каждом кластере
- Вычисляет процентное соотношение
- Сохраняет отдельно для метода TF-IDF и метода embeddings
- Позволяет оценить соответствие естественной группировки формальной классификации

---

## Интеграция с базой данных

Все этапы пайплайна работают с базой данных:

| Этап | Таблица БД | Что сохраняется |
|------|-----------|-----------------|
| Парсинг | `articles` | Метаданные и тексты статей |
| LDA | `lda_results` | Токены, ключевые слова доминантных тем |
| Кластеризация | `clustering_results` | Принадлежность к кластерам, названия кластеров |
| Классификация ВАК | `vak_results` | Коды топ-1 специальностей для обоих методов (TF-IDF и embeddings) |
| Аналитика | `cluster_vak_tfidf_distribution`, `cluster_vak_embed_distribution` | Статистика распределения по кластерам |

**Преимущества:**
- Централизованное хранение всех данных
- Целостность данных через внешние ключи
- Быстрые запросы через индексы
- Возможность SQL-анализа результатов
- История всех обработок

См. `backend/database.py` для полной схемы базы данных.
