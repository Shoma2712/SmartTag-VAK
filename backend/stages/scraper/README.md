# Блок 2: Сбор PDF файлов с сайта IMT Journal

## Описание

Этот блок отвечает за автоматический сбор PDF файлов научных статей с сайта журнала «Информационные и математические технологии в науке и управлении» (IMT Journal). Он обеспечивает скачивание статей из архива журнала для последующего парсинга и анализа.

## Основные функции

### `download_pdf(pdf_url: str) -> bool`

Скачивает PDF файл по указанному URL.

**Параметры:**
- `pdf_url` (str): URL PDF файла

**Возвращает:**
- `bool`: True если файл скачан успешно, False если уже существует или произошла ошибка

**Что делает:**
- Проверяет, существует ли файл в локальной папке
- Если файл уже есть, пропускает скачивание
- Выполняет HTTP-запрос с заголовком User-Agent (эмуляция браузера)
- Сохраняет файл в директорию `pdf_dir`
- Выводит статус скачивания

**Пример использования:**
```python
scraper = IMTScraper("project_data/pdfs/imt")
scraper.download_pdf("https://imt-journal.ru/articles/article1.pdf")
# Скачивание: article1.pdf
```

---

### `get_pdfs_from_page(page_url: str) -> list`

Извлекает все ссылки на PDF файлы со страницы архива.

**Параметры:**
- `page_url` (str): URL страницы для парсинга

**Возвращает:**
- `list`: Список URL-ов PDF файлов

**Что делает:**
- Загружает HTML-страницу по указанному URL
- Парсит HTML с помощью BeautifulSoup
- Находит все ссылки (`<a>` теги) с расширением `.pdf`
- Формирует полные URL-адреса (добавляет базовый домен при необходимости)
- Исключает дубликаты ссылок
- Выводит количество найденных PDF

**Пример использования:**
```python
pdfs = scraper.get_pdfs_from_page("https://imt-journal.ru/archive")
print(len(pdfs))  # 15
```

---

### `find_next_page(current_page_url: str)`

Находит ссылку на следующую страницу пагинации.

**Параметры:**
- `current_page_url` (str): URL текущей страницы

**Возвращает:**
- `str`: URL следующей страницы или `None` если следующей страницы нет

**Что делает:**
- Загружает текущую страницу
- Ищет блок пагинации (`.pagination`)
- Находит текущую активную страницу и берет следующую за ней
- Альтернативный поиск по тексту («Вперед», «Next», «>»)
- Возвращает полный URL следующей страницы

---

### `run(max_pages: int = 50, delay: float = 0.5)`

Запускает процесс сбора PDF файлов.

**Параметры:**
- `max_pages` (int): Максимальное количество страниц для обхода (по умолчанию 50)
- `delay` (float): Задержка между запросами в секундах (по умолчанию 0.5)

**Возвращает:**
- `dict`: Статистика сбора:
  - `pages_processed`: количество обработанных страниц
  - `files_downloaded`: количество скачанных новых файлов

**Что делает:**
1. Последовательно обходит страницы архива (начиная с `/archive`)
2. На каждой странице извлекает ссылки на PDF
3. Скачивает каждый PDF файл
4. Соблюдает задержку между запросами (чтобы не перегружать сервер)
5. Переходит на следующую страницу через пагинацию
6. Останавливается при достижении `max_pages` или если страниц больше нет
7. Выводит итоговую статистику

**Пример вывода:**
```
================================================================================
ЗАПУСК СБОРА PDF
================================================================================

Страница 1: https://imt-journal.ru/archive
Найдено PDF: 15
Скачивание: article_1.pdf
Скачивание: article_2.pdf
...

Страница 2: https://imt-journal.ru/archive?page=2
Найдено PDF: 12
...

================================================================================
СБОР ЗАВЕРШЕН
================================================================================
Обработано страниц: 5
Скачано новых файлов: 67
```

### `run_scraper(pdf_dir: str, max_pages: int = 50)`

Удобная функция для запуска скрейпера.

**Параметры:**
- `pdf_dir` (str): Путь к директории для сохранения PDF
- `max_pages` (int): Максимальное количество страниц

**Возвращает:**
- `dict`: Статистика сбора

**Пример использования:**
```python
from backend.stages.scraper import run_scraper

stats = run_scraper("project_data/pdfs/imt", max_pages=50)
print(stats)
# {'pages_processed': 5, 'files_downloaded': 67}
```

## Класс `IMTScraper`

Основной класс для скачивания PDF файлов с сайта журнала IMT.

**Атрибуты:**
- `base_url`: Базовый URL журнала (`https://imt-journal.ru`)
- `archive_url`: URL страницы архива (`https://imt-journal.ru/archive`)
- `pdf_dir`: Путь к директории для сохранения PDF
- `headers`: Заголовки HTTP-запросов (User-Agent)

**Инициализация:**
```python
scraper = IMTScraper(pdf_dir="project_data/pdfs/imt")
```

## Зависимости

- `os`: Работа с файловой системой
- `requests`: HTTP-запросы для скачивания файлов
- `time`: Задержки между запросами
- `bs4` (BeautifulSoup): Парсинг HTML страниц
- `urllib.parse`: Работа с URL

---

## Примечания

- Скрейпер соблюдает задержку между запросами (по умолчанию 0.5 сек), чтобы не перегружать сервер
- Если PDF файл уже существует в папке, он не скачивается повторно
- Максимальное количество обрабатываемых страниц ограничено параметром `max_pages`
- Скрейпер эмулирует браузер через заголовок User-Agent
- Блок безопасен для многократного запуска (пропускает уже скачанные файлы)
