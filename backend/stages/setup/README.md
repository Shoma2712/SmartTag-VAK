# Block 1: Инициализация проекта

## Описание

Этот блок отвечает за начальную настройку окружения и создание структуры папок для проекта SmartTag VAK. Он подготавливает все необходимые ресурсы и директории для последующей работы с научными статьями.

## Основные функции

### `download_nltk_resources()`

Загружает необходимые ресурсы NLTK для обработки русского текста.

**Возвращает:**
- `bool`: True если ресурсы загружены успешно

**Что делает:**
- Проверяет наличие корпуса stopwords (стоп-слов)
- Если отсутствует, автоматически загружает его
- Выводит статус загрузки

**Пример использования:**
```python
download_nltk_resources()
# ✓ NLTK stopwords уже загружены
```

---

### `setup_project_structure(base_dir="project_data")`

Создает структуру папок для хранения данных проекта.

**Параметры:**
- `base_dir` (str): Название базовой директории проекта (по умолчанию "project_data")

**Возвращает:**
- `dict`: Словарь с путями к основным директориям:
  - `BASE_DIR`: Базовая директория проекта
  - `PDF_DIR`: Директория для PDF файлов
  - `PDF_IMT`: Директория для PDF файлов журнала IMT
  - `OUTPUT_IMT`: Путь к выходному CSV файлу с парсированными данными

**Что делает:**
- Создает базовую директорию проекта
- Создает поддиректории для PDF файлов
- Создает специальную папку для журнала IMT
- Выводит информацию о созданных путях

**Пример использования:**
```python
paths = setup_project_structure()
print(paths['BASE_DIR'])  # C:\Users\...\project_data
print(paths['PDF_IMT'])   # C:\Users\...\project_data\pdfs\imt
```

---

### `initialize_project()`

Главная функция инициализации проекта. Объединяет все шаги подготовки.

**Возвращает:**
- `dict`: Словарь с путями к основным директориям

**Что делает:**
1. Загружает ресурсы NLTK
2. Создает структуру папок проекта
3. Выводит информацию об успешной инициализации

**Пример использования:**
```python
from backend.stages.setup import initialize_project

paths = initialize_project()
# ================================================================================
# ИНИЦИАЛИЗАЦИЯ ПРОЕКТА
# ================================================================================
# 
# ✓ NLTK stopwords уже загружены
# ✓ Рабочая папка: C:\Users\...\project_data
# ✓ IMT PDF: C:\Users\...\project_data\pdfs\imt
# 
# ✓ Проект инициализирован успешно!
# ================================================================================
```

## Дополнительные настройки

Блок также выполняет следующие настройки окружения:

### Отключение предупреждений
- Отключает DeprecationWarning, UserWarning, FutureWarning
- Отключает предупреждения о datetime.utcnow
- Отключает предупреждения о многопоточности

### Настройка логирования
- Устанавливает уровень ERROR для логгеров pdfminer
- Убирает лишний вывод при парсинге PDF

## Структура создаваемых папок

```
project_data/

│   └── imt/              # PDF файлы журнала IMT
└── dataset_IMT.csv       # Парсированные данные (создается позже)
```

## Запуск

Блок можно запустить как отдельный модуль:

```bash
python blocks/block_1_setup/setup.py
```

Или импортировать в другой код:

```python
from backend.stages.setup import initialize_project

paths = initialize_project()
```

## Зависимости

- `os`: Работа с файловой системой
- `warnings`: Управление предупреждениями
- `logging`: Настройка логирования
- `nltk`: Natural Language Toolkit для обработки текста
- `pathlib`: Работа с путями

---

## Примечания

- Все пути создаются относительно текущей рабочей директории
- Если папки уже существуют, они не пересоздаются
- NLTK ресурсы загружаются только при первом запуске
- Блок безопасен для многократного запуска
