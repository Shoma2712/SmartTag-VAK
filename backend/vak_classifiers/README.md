# Модуль `vak_classifiers`

## Описание

Классификация научных статей по пяти специальностям ВАК журнала "Информационные и математические технологии в науке и управлении".

**`ui_classifier.py`** — основной классификатор для UI и пайплайна: 
- Ранжирование top-3 по методу Sentence Embeddings (семантическая близость)
- Дополнительная проверка методом TF-IDF (статистическое сходство терминов)
- Выявление неоднозначных случаев и расхождений между методами
- Сохранение результатов в базу данных SQLite

---

## `ui_classifier.py` — двухметодный классификатор

### Принцип работы

Система использует **два независимых метода** классификации:

1. **Sentence Embeddings метод** (основной):
   - Семантический анализ через нейросетевые модели
   - Сравнение с короткими описаниями специальностей ВАК
   - Используется для основного ранжирования и топ-3 рекомендаций
   - Отображается как проценты на основе сырого cosine similarity (20-70%)

2. **TF-IDF метод** (валидация):
   - Статистический анализ частоты терминов
   - Сравнение с полными описаниями специальностей ВАК
   - Используется для выявления расхождений и альтернативных рекомендаций

### Типичные значения косинусного сходства

**Важно:** Низкие абсолютные значения косинусного сходства — это нормально для данной задачи!

| Метод | Типичный диапазон | Причина |
|-------|-------------------|---------|
| **Embeddings** (основной) | **0.2 - 0.7** (20-70%) | Семантические представления более плотные; модель обучена на научных текстах |
| **TF-IDF** (дополнительный) | **0.03 - 0.15** | Сравнение коротких текстов; большой словарь (40k терминов); разреженные векторы |

**Почему TF-IDF даёт низкие значения:**
- Короткие описания специальностей ВАК (3-5 предложений)
- Ограниченный фрагмент текста статьи (~3000 символов)
- Минимальное пересечение терминов между статьёй и описанием ВАК
- Высокая размерность пространства признаков (40,000 терминов)

**Что важно:** Не абсолютное значение, а **относительное ранжирование** между специальностями.

### Режимы отображения

**Режим cosine (по умолчанию):**
- Отображает сырые значения косинусного сходства embeddings
- Диапазон: 0.2 - 0.7
- Показывается как проценты: 20% - 70%
- Честно отражает степень семантической близости

### Типы и конфигурация

#### `VakUiConfig` (dataclass)

| Поле | По умолчанию | Смысл |
|------|----------------|-------|
| `embed_model_name` | `mlsa-iai-msu-lab/sci-rus-tiny3.1` | Модель sentence-transformers для научных текстов |
| `main_text_max_chars` | 3000 | Сколько символов `main_text` добавить к TF-IDF |
| `field_weights` | title×3, annotation×2, keywords×2 | Веса полей при построении текста |
| `score_mode` | `"cosine"` | Режим отображения (всегда cosine для embeddings) |
| `ambiguous_gap` | 0.02 | Порог неоднозначности (разница в 2%) |
| `tfidf_alternative_min_gap` | 0.02 | Минимальный разрыв для альтернативной рекомендации TF-IDF |
| `top_k` | 3 | Размер топ-N для отображения |

#### `SpecialtyScore`, `UiFlags`, `VakUiResult`

Структуры ответа: 
- `SpecialtyScore`: код ВАК, название, `match_score` (Embeddings, основной), `tfidf_similarity` (TF-IDF, дополнительный), ранги
- `UiFlags`: флаги `ambiguous` (неоднозначность), `discrepancy` (расхождение методов), `message` (подсказка пользователю)
- `VakUiResult`: `top3`, `all_specialties`, `flags`

Методы: `to_dict()`, `to_json()` для сериализации.

### Функции

#### `vak_code(full_name: str) -> str`

Извлекает код вида `2.3.1` из полного ключа специальности.

#### `build_semantic_input(row, config) -> str`

**Вход:** словарь или `Series` с полями статьи, `VakUiConfig`.

**Выход:** строка = взвешенные meta (title×3, annotation×2, keywords×2), **без** `main_text`.

**Назначение:** текст для эмбеддингов (только метаданные; полный текст ухудшает разделение классов). Используется для основного ранжирования.

#### `build_tfidf_input(row, config) -> str`

**Вход:** словарь или `Series` с полями статьи, `VakUiConfig`.

**Выход:** строка = взвешенные meta (title×3, annotation×2, keywords×2) + начало `main_text` (до 3000 символов).

**Назначение:** корпус для сравнения с полными описаниями ВАК через TF-IDF. Используется для дополнительной валидации.

### Класс `VakUiClassifier`

#### `__init__(config=None)`

Инициализирует классификатор с заданной конфигурацией. Модель эмбеддингов загружается лениво при первом использовании.

#### `classify_row(row, corpus_tfidf_texts=None) -> VakUiResult`

**Вход:** 
- `row`: словарь или Series с полями статьи (title, annotation, keywords, main_text)
- `corpus_tfidf_texts`: опциональный список текстов для пакетной обработки

**Выход:** `VakUiResult` с топ-3 специальностями, всеми специальностями, флагами.

**Логика:** 
1. Embeddings косинусное сходство по 5 специальностям ВАК (основной метод)
2. Параллельно: TF-IDF косинусное сходство по полным описаниям ВАК (дополнительный)
3. Ранжирование по embeddings scores (сырой cosine, 0.2-0.7)
4. Определение флагов неоднозначности (разрыв < 2%) и расхождения между методами
5. Формирование подсказок для пользователя

#### `classify_text(text_tfidf, text_semantic=None) -> VakUiResult`

Классификация одной произвольной строки (упрощённый интерфейс).

#### `classify_dataframe(df) -> pd.DataFrame`

**Вход:** DataFrame со статьями.

**Выход:** копия DataFrame с добавленными колонками:
- `vak_ui_top1_code`: код топ-1 специальности (по embeddings)
- `vak_ui_top1_match_score`: семантическое сходство топ-1 (сырой cosine, 0.2-0.7)
- `vak_ui_ambiguous`: флаг неоднозначности (разрыв < 2%)
- `vak_ui_discrepancy`: флаг расхождения методов (embeddings vs TF-IDF)
- `vak_ui_message`: текстовая подсказка для пользователя
- `vak_ui_json`: полный результат в формате JSON

**Использование:** Пакетная классификация корпуса статей с сохранением в базу данных.

---

### `classify_for_ui(df, main_text_max_chars=3000) -> pd.DataFrame`

Удобная обёртка для ноутбука: создаёт `VakUiClassifier` с дефолтной конфигурацией и вызывает `classify_dataframe`.

## Интеграция с базой данных

Результаты классификации сохраняются в таблицу `saved_classifications` базы данных SQLite:
- Метаданные статьи (title, annotation, keywords, main_text)
- Результаты обоих методов:
  - `vak_embed_code`, `vak_embed_score` — Embeddings (основной метод)
  - `vak_tfidf_code`, `vak_tfidf_score` — TF-IDF (дополнительный метод)
- Топ-3 специальности в формате JSON
- Флаги неоднозначности и расхождения
- Временная метка и заметки пользователя

См. `backend/database.py` для схемы базы данных.
