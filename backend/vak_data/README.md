# Модуль `vak_data`

## Описание

Данные и подготовка текста для классификаторов ВАК: официальные формулировки пяти специальностей журнала, сборка взвешенного текста статьи, чтение строк из базы данных SQLite.

## Файлы

| Файл | Содержимое |
|------|------------|
| `descriptions.py` | `VAK_DESCRIPTIONS` и константы имён специальностей |
| `texts.py` | Сборка текста статьи для TF-IDF и эмбеддингов |
| `loader.py` | Загрузка и поиск статей в базе данных SQLite |

---

## `descriptions.py`

### `VAK_DESCRIPTIONS: Dict[str, str]`

Словарь «полное имя специальности ВАК → официальный текст перечня направлений». Ключи включают код и название, например `"1.2.2. Математическое моделирование, ..."`. Используется во всех классификаторах как эталонный корпус ВАК.

### Константы имён

- `VAK_MATH`, `VAK_SYSTEM`, `VAK_AUTO`, `VAK_SOFTWARE`, `VAK_ENERGY` — полные строки-ключи для правил в гибридном классификаторе (`embedding_hybrid.py`).

**Вход / выход:** только данные, функций нет.

---

## `texts.py`

### `_normalize_text(text: str) -> str`

**Параметры:** `text` — произвольная строка.

**Возвращает:** строку в нижнем регистре без знаков препинания (пробелы схлопнуты).

**Назначение:** вспомогательная нормализация (зарезервировано для лексических правил).

---

### `compress_vak_description(description: str, max_sentences: int = 4) -> str`

**Параметры:**

- `description` — полный официальный текст специальности.
- `max_sentences` — сколько фрагментов (по разделителю `". "`) оставить.

**Возвращает:** укороченное описание для эмбеддингов.

**Что делает:** берёт первые предложения/пункта перечня ВАК, как в паспорте специальности.

---

### `build_article_text(row, fields=..., weights=..., max_chars=8000) -> str`

**Параметры:**

- `row` (`pd.Series`) — строка статьи (поля `title`, `annotation`, `keywords`, …).
- `fields` — какие колонки включать.
- `weights` — повторение текста поля (например `title: 3` → три копии подряд).
- `max_chars` — обрезка итоговой строки.

**Возвращает:** одну строку — конкатенация выбранных полей с весами.

**Что делает:** формирует вход для эмбеддингов (обычно **без** полного `main_text`) и базовую часть для TF-IDF.

---

## `loader.py`

### `load_dataset(db_path=None, conn=None) -> pd.DataFrame`

**Параметры:** 
- `db_path` — путь к базе данных SQLite; если `None`, берётся `DEFAULT_DB_PATH` из `backend.config`
- `conn` — существующее соединение с базой данных (опционально)

**Возвращает:** DataFrame со всеми статьями из таблицы `articles`.

**Исключения:** `FileNotFoundError`, если база данных отсутствует.

**Что делает:** Загружает все статьи из базы данных через `get_all_articles(conn)`.

---

### `find_article(df, *, title=None, index=None, article_id=None) -> pd.Series`

**Параметры:**

- `df` — загруженный датасет.
- `title` — точное совпадение по колонке `title` (после `strip`).
- `index` — целочисленный индекс строки в DataFrame.
- `article_id` — ID статьи в базе данных.

**Возвращает:** одну строку `pd.Series`.

**Исключения:** `KeyError` если название не найдено; `ValueError` если не указан ни один из параметров поиска.

**Что делает:** Ищет статью по заголовку, индексу или ID в базе данных.

---

### `row_to_fields(row) -> Dict[str, str]`

**Параметры:** строка DataFrame или словарь.

**Возвращает:** словарь с ключами `title`, `annotation`, `keywords`, `main_text` (пустые строки вместо `NaN`).

**Назначение:** единый формат для `VakUiClassifier.classify_row()` и CLI.
