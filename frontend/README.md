# Модуль `frontend` — Tkinter UI

## Описание

Графический интерфейс для классификации научных статей по специальностям ВАК. Окно «Подбор специальности ВАК» предоставляет:

- **Ввод данных:** четыре поля (название, аннотация, ключевые слова, основной текст)
- **Двухметодная классификация:** Sentence embeddings (основной) + TF-IDF (валидация)
- **Результаты:** таблица топ-3 специальностей с оценками сходства (проценты на основе cosine similarity)
- **Детальный просмотр:** все 5 специальностей с результатами обоих методов
- **Интеллектуальные подсказки:** флаги неоднозначности и расхождения между методами
- **Сохранение в БД:** возможность сохранить результаты классификации в базу данных SQLite с заметками

Зависимости: `tkinter`, `pandas`, `backend.vak_classifiers.ui_classifier`, `backend.database`.

## Константы

- `MIN_TEXT_LEN = 30` — минимальная суммарная длина всех полей перед запуском классификации.
- `DB_PATH` — путь к базе данных SQLite (`project_data/smarttag_vak.db`).

## Класс `VakClassifierApp(tk.Tk)`

### `__init__()`

Создаёт окно 960×900, инициализирует UI, запускает фоновую предзагрузку модели эмбеддингов (`after(200, _preload_model)`).

**Состояние:**

- `_classifier` — ленивый `VakUiClassifier` с режимом `score_mode='cosine'`;
- `_busy` — блокировка повторного нажатия;
- `_last_result` — последний `VakUiResult` для режима «Подробнее» и сохранения в БД.

---

### `_build_ui() -> None`

**Что делает:** размещает подсказку, форму из четырёх `ScrolledText`, кнопки «Подобрать», «Вставить», «Очистить», «Сохранить в БД», чекбокс «Подробнее», статус, фрейм флагов, `Treeview` для top-3 и детальной таблицы.

**Выход:** только изменение виджетов.

**Новое:** кнопка «Сохранить в БД» для записи результатов классификации в базу данных с возможностью добавления заметок.

---

### `_add_field(parent, label, height, first=False) -> ScrolledText`

**Параметры:** родительский фрейм, подпись, высота в строках.

**Возвращает:** виджет текста с привязкой буфера обмена и фокуса.

---

### `_collect_article_fields() -> Dict[str, str]`

**Возвращает:** `title`, `annotation`, `keywords`, `main_text` из полей формы.

---

### `_on_classify() -> None`

**Вход:** текст из полей (проверка длины и наличия title/annotation).

**Что делает:** в отдельном потоке вызывает `VakUiClassifier.classify_row(pd.Series(fields))`, по завершении — `_show_result` в главном потоке Tk.

**Режим отображения:** `score_mode='cosine'` — сырые значения cosine similarity (отображаются как проценты, например 0.543 → "54.3%").

**Выход:** обновление таблиц и подсказок; при ошибке — `messagebox`.

---

### `_show_result(result: VakUiResult) -> None`

Заполняет top-3 (`match_score` как проценты на основе embeddings cosine similarity), текст флагов (`ambiguous`, `discrepancy`, `message`), обновляет детальную таблицу если включена.

**Интерпретация значений:**
- **60-70%** — высокое семантическое соответствие (рекомендуется)
- **50-60%** — хорошее соответствие (возможный вариант)
- **40-50%** — среднее соответствие (требует проверки)
- **20-40%** — низкое соответствие

---

### `_refresh_details() -> None`

Показывает/скрывает фрейм «Подробнее»; выводит все 5 специальностей с `match_score` (embeddings, сырой), `tfidf_similarity` (TF-IDF, сырой) и рангами обоих методов.

**Колонки детальной таблицы:**
- Код ВАК
- Название специальности
- Семант. сходство (%) — сырое значение embeddings cosine similarity (20-70%)
- Ранг Embed — позиция по методу embeddings
- TF-IDF сходство — сырое значение TF-IDF (0.03-0.15)
- Ранг TF-IDF — позиция по методу TF-IDF

---

### `_on_save_to_db() -> None`

**Новая функция:** Сохраняет результаты последней классификации в базу данных SQLite.

**Что делает:**
1. Проверяет наличие результатов классификации (`_last_result`)
2. Проверяет доступность соединения с базой данных
3. Извлекает данные из `_last_result`:
   - Метаданные статьи (title, annotation, keywords, main_text)
   - Топ-1 специальности для обоих методов (Embeddings и TF-IDF)
   - Степени соответствия (сырые значения cosine similarity)
   - Топ-3 специальности в формате JSON
   - Флаги неоднозначности и расхождения
4. Записывает в таблицу `saved_classifications` с временной меткой
5. Показывает сообщение об успешном сохранении с ID записи

**Использование:** Позволяет накапливать историю классификаций для последующего анализа и статистики.

---

### `_preload_model()` / `_load_classifier()` / `_get_classifier()`

Фоновая и синхронная загрузка `VakUiClassifier(VakUiConfig(score_mode='cosine'))` с блокировкой `threading.Lock`; статусная строка «Модель загружается…» / «Готово».

**Важно:** Используется режим `cosine` для отображения сырых значений cosine similarity как процентов.

---

### `_on_clear()`, `_clear_results()`, `_set_busy(busy, message)`

Очистка полей и таблиц; отключение кнопок на время классификации.

## Интеграция с базой данных

Результаты классификации сохраняются в таблицу `saved_classifications`:

| Поле | Описание |
|------|----------|
| `title`, `annotation`, `keywords`, `main_text` | Метаданные статьи |
| `vak_embed_code`, `vak_embed_title`, `vak_embed_score` | Топ-1 по embeddings (основной метод) |
| `vak_tfidf_code`, `vak_tfidf_title`, `vak_tfidf_score` | Топ-1 по TF-IDF (валидация) |
| `top3_json` | Топ-3 специальности (JSON) |
| `is_ambiguous`, `has_discrepancy` | Флаги проблемных случаев |
| `timestamp` | Время классификации |
| `notes` | Заметки пользователя (опционально) |

**Запросы к БД:** См. `backend/database.py` для схемы и примеров запросов.

## Типичные значения и интерпретация

### Embeddings (match_score, основной метод)

Сырые значения косинусного сходства (отображаются как проценты):
- **60-70%** (0.6-0.7) — высокое семантическое соответствие (рекомендуется)
- **50-60%** (0.5-0.6) — хорошее соответствие (возможный вариант)
- **40-50%** (0.4-0.5) — среднее соответствие (требует проверки)
- **20-40%** (0.2-0.4) — низкое соответствие

**Важно:** Показываются как проценты для удобства (например, 0.543 → "54.3%"), но это сырые значения cosine similarity, а не нормализация.

### TF-IDF (tfidf_similarity, валидация)

Сырые значения косинусного сходства:
- **0.10-0.15** — высокое соответствие для TF-IDF
- **0.05-0.10** — среднее соответствие
- **0.03-0.05** — низкое соответствие

**Важно:** Абсолютные значения TF-IDF косинуса низкие из-за коротких текстов и большого словаря. TF-IDF используется как вспомогательный метод для валидации результатов embeddings.

## `main() -> None`

**Что делает:** `VakClassifierApp().mainloop()`; при отсутствии Tkinter — сообщение в stderr и `sys.exit(1)`.

**Запуск:** `python -m frontend.tkinter_app`.
